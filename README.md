📚 Order Management System
A Spring Boot–based RESTful application for managing book orders with seamless integration of JPA and MySQL.
This project demonstrates clean backend architecture, database persistence, and web service development using modern Java practices.

🔑 Features
Spring Boot 4.1.0 with Maven build support

Spring Data JPA for ORM and database operations

MySQL Connector for relational data storage

Spring Web MVC for RESTful endpoints and web content serving

DevTools for rapid development and hot reload

Test dependencies for JPA and Web MVC modules

🚀 Getting Started
Clone the repository

Configure your MySQL database in application.properties

Run the application with mvn spring-boot:run

Access REST endpoints to manage book orders
